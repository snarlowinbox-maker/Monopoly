\# Monopoly · 3-Player Online



A polished online multiplayer Monopoly game for exactly \*\*3 players\*\*, using the classic Atlantic City board. Built with \*\*Node.js + Socket.io\*\* (authoritative server) and \*\*React + TypeScript + Vite\*\* (client). Runs locally in two commands.



\## Requirements



\- Node.js 18+

\- npm 9+



\## Run locally



```bash

\# 1. From the project root:

npm install



\# 2. Start both dev servers (server on :4000, client on :5173):

npm run dev
